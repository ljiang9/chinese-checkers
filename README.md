# chinese-checkers 跳棋

双人六角星跳棋：把 10 颗子全部送进对方营地获胜。纯 Python 标准库，文字棋盘。

## 玩法

- 你是 `●`（玩家 0，上方营地出发），AI 是 `○`（玩家 1）。
- 每轮走一子：**走**到相邻空格，或**跳**过相邻任意棋子落到空位，可连跳。
- 一回合只能二选一：走一步，或完成一串连跳。
- 10 颗子全部进入对方营地（底部角）即胜。

## 用法

```bash
python3 -m chinese_checkers            # 人机对战（你是 ●）
python3 -m chinese_checkers --auto 6  # AI 对 AI 下 6 局
python3 -m chinese_checkers --auto 6 --seed 7 --plies 600
```

人机对战时，每轮会列出所有合法走法（标 `走`/`跳`），输入序号即可，`q` 退出。

## AI 说明

贪心 AI：每步最小化「各子到最近未填满目标格的距离」——先推进最落后的子，
已进营的子不许出来；另有两处防呆：

- 禁止立即走回头路（破二人转式 2-循环）；
- 5% 概率随机走子，帮助逃离贪心局部最优；
- 残局仍设 600 手上限 + 局面三次重复判和，兜底。

## 真实验证记录

- `py_compile` 通过。
- 8 项单元测试全过：121 格棋盘结构（6 角各 10 格、互不重叠）、开局布子、
  步进合法、连跳（隔子两连跳）、占位拒绝、无中子跳跃拒绝、目标营填满判胜、
  AI 走法确使进度不退。
- `--auto` 实测：seed 7 连下 6 局，比分 5:1，0 和棋；
  另 10 个随机种子 10 局全部分出胜负（8:2），平均约 151 手。

## 已知局限（诚实版）

- 只有双人对战（标准跳棋可 2/3/4/6 人），没有实现多人。
- AI 是贪心+扰动，不是强 AI：不会做长连跳规划，残局偶尔绕路。
- 文字棋盘，无图形界面；无存档、无悔棋。
- Python 3.10+。
